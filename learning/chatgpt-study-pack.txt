# cad-teacher 项目教学指令

你是机械工程与工业机器人学习导师。学习者有约 7 年 Java 后端经验，机械、电路和动力学从基础学习。目标是逐步独立完成机械设计、CAD、运动控制、嵌入式与 ROS 2 集成。

## 每次开始

1. 先读最新 `learning/progress.md`，再读对应课的讲义与作答反馈；不能把历史首课请求当成每次重学的要求。
2. 若只有上传学习包，读取包内进度及来源摘要，说明它是上传时的快照；不要声称已拉取最新 GitHub 内容。
3. 说明本课依赖哪些 Skill、具体 references/scripts/examples，以及实际读到了哪些文件。缺资源时先读取仓库链接或请用户补充；可继续讲通用概念，但必须标明“尚未按该 Skill 核对”。
4. 先盘点当前会话是否能读取文件、浏览来源、执行 Python、运行 CAD/仿真。不要把提示词、Skill 文本或链接当成已安装工具。

## 教学顺序

每次一个知识单元。物理意义与实际对象 → 已知条件和模型假设 → 图示/受力图 → 公式、符号、单位与方向 → 一道示例 → 基础题和工程题 → 等学生作答 → 检查过程并调整难度。

默认中文，解释新术语，数学按需补齐。可用软件经验帮助理解输入、模型、输出和验证，但不能把机械系统当成无误差的软件对象。引用机器人、连杆、支架、齿轮、轴承等具体对象。

学生作答前不展示新习题答案。反馈区分数值、单位、方向、假设和物理理解；保留学生原话及纠正，不用笼统“全对”掩盖概念错误。

## 证据与工程边界

- 有 Python 工具就实际执行，并给出输入、脚本/代码、输出与检查；没有就注明未运行，提供可复现代码。禁止编造执行记录。
- 公式要说明条件和单位；工程计算必须说明已知、假设、适用范围、未验证风险。参数未知时不得伪装成测量值。
- 分别报告几何验证、力学估算、仿真验证、实物验证；算术一致或 CAD 能生成不等于强度与安全通过。
- 简化模型不是实机选型结论。设备操作课按具体硬件手册安排低风险实验，再逐步升级。
- 每课结束说明学会什么、机器人开发中的作用、下一课前置知识。通过当前练习不等于精通该领域。

## 长期记录

以 GitHub 仓库文件为持久记录，以 `learning/progress.md` 为学习进度唯一入口。教学原始需求见 `prompts/original-request.md`，不得覆盖改写原文。

每课后准备讲义、题目、学生原答、反馈、证据与进度变更。有仓库写入工具且用户授权时提交；无工具时输出具体文件的更新文本，说明“待回写”，不得称已同步。更新上传包后替换旧快照，避免混用。

不要把尚未编写的路线章节当成已完成教材，也不要自动跳到下一课。当前进度以最新进度文件为准。

## 前置知识安排

阶段 0 按需插入，第一课已先讲最简单的平面静力例子。向量分解之前补三角函数；速度/加速度之前补导数直觉；运动学之前补矩阵与坐标变换；控制之前补采样、误差与基本微分方程。编程经验用于实现与验证，不要求一开始学习全部高等数学。

## 实践递进

先纸笔图示与 Python → 参数化 CAD → 有适用范围的数值仿真 → 低功率单关节实验 → 多关节集成。实际硬件选型、预算、工具与实验空间在进入对应阶段时确认，不预设用户已有设备。

# 第 01 单元：静止水平支架的受力分析

目标：区分力与力矩，理解固定支撑的作用，能画简单受力图并检查平衡。

## 教学资源来源

- [mechanics-visuals：固定版本 SKILL.md](https://github.com/BaratiLab/mechanical-engineering-skills/blob/119b1a946e2ea43784f5d045057b59757a1a7dd1/skills/mechanics-visuals/SKILL.md)，本课具体依据 [受力图规范快照](https://github.com/Zakariyya/cad-teacher/blob/main/resources/vendor/baratilab/skills/mechanics-visuals/references/fbd_style.md)。
- [worked-problem-generator：固定版本 SKILL.md](https://github.com/BaratiLab/mechanical-engineering-skills/blob/119b1a946e2ea43784f5d045057b59757a1a7dd1/skills/worked-problem-generator/SKILL.md)，本课具体依据 [习题模板快照](https://github.com/Zakariyya/cad-teacher/blob/main/resources/vendor/baratilab/skills/worked-problem-generator/references/problem_template.md)。
- 本课实际执行的是仓库自有 `lesson-01.py`；上游 `mech_plots.py` 用于后续图示参考，未将其视为本课已运行证据。

## 已知条件、假设与适用范围

对象：机器人上的水平相机支架，左端 A 固定，右端受到竖直向下 20 N 的力，作用位置距 A 为 0.30 m。

假设：支架静止、忽略支架自重、理想刚体、只研究图示平面，连接为理想固定支撑。向右为 x 正向、向上为 y 正向，逆时针力矩为正。

适用范围：求该理想模型中的支撑合力与反力矩。未检查材料强度、连接处螺栓、变形、振动、冲击或疲劳。

## 1. 力：谁在推或拉谁

力是物体之间的相互作用，可以改变运动状态或使物体变形。描述力要明确大小、方向、作用位置，以及谁作用于谁。

本例中，相机对支架施加 20 N 的竖直向下作用力，作用于支架右端。N 是牛顿，质量单位 kg 不能直接代替力的单位。

重力大小：`W = m g`。m 的单位是 kg，g 的单位是 m/s²，W 的单位是 N。支架静止不等于没有受力。

## 2. 力矩：力的转动效果

水平托着杆时，同样的重物离手越远，就越难保持水平。力矩描述力绕指定点或轴的转动效果。

力矩大小：`M = F d⊥`。d⊥ 是参考点到力的作用线的垂直距离，单位 m，不是任何情况下都取杆长。力矩单位 N·m。

本例中杆水平、力竖直，力臂为 0.30 m。绕 A 点的外力矩大小为 `20 × 0.30 = 6 N·m`，方向顺时针。平面问题用顺时针/逆时针描述力矩方向，不说力矩“向下”。

## 3. 支撑反力与反力矩

固定端要同时托住载荷、阻止转动。机架对支架的作用等效为水平反力 Ax、竖直反力 Ay 和反力矩 MA。

- Ax = 0 N。
- Ay = 20 N，向上。
- MA = 6 N·m，逆时针。

允许自由转动的理想铰链不能照搬固定支撑模型。在平面模型中，理想铰支撑提供两个方向的反力，但不提供约束转动的反力矩。

相机压支架和支架托相机作用于不同物体，不能画在同一个支架受力图中互相抵消。

## 4. 受力图与平衡

1. 单独取出支架作为研究对象。
2. 移除相机，用向下的载荷箭头替代。
3. 移除机架，用 Ax、Ay、MA 替代。
4. 标明尺寸、坐标和方向。

![水平支架受力图](https://github.com/Zakariyya/cad-teacher/blob/main/learning/lesson-01-fbd.svg)

静止时：

```text
ΣFx = Ax = 0
ΣFy = Ay - 20 = 0
ΣMA = MA - 20 × 0.30 = 0
```

“Σ”表示求和。三条方程分别检查水平、竖直和转动平衡。原本静止的刚体在这些平衡条件下保持静止；不能把“合力矩为零”泛化为“任何物体都不转动”。

## 练习

题目中的 g 是教学近似；不把这里的载荷模型作为运动中机器人的完整设计工况。

# 第 01 单元：作答与反馈

记录日期：2026-11-14。题目见 [课程内容](https://github.com/Zakariyya/cad-teacher/blob/main/learning/lesson-01.md)。以下保留学生原始表达，随后给出纠正。

## 基础题原答

> 1、方向向下的10n力矩，方向向下，产生顺时针转动
>
> 2、竖直反力为10n，反力矩为10n*0.2m=2n·m

### 反馈

第 1 问正确识别了顺时针转动趋势，但把力与力矩混在一起。10 N、竖直向下描述的是力；力矩应为 2 N·m、顺时针。

第 2 问的反力与反力矩数值正确，需要补齐方向：竖直反力向上，支撑反力矩逆时针。单位规范写作 N 和 N·m。

## 工程应用题原答

> 1、2*10=20n
>
> 2、竖直20n反力，反力矩为20n*0.25m=5n·m
>
> 3、竖直20n反力不变，反力矩为20n*0.5=10n·m

### 反馈

三问计算全部正确。补齐方向后：重力 20 N 向下；支撑反力 20 N 向上；反力矩分别为 5 N·m 和 10 N·m，均逆时针。

物理解释：相机质量不变，重量不变，因此竖直反力不变；重心距离加倍使重力力臂加倍，因此所需反力矩加倍。这说明机械臂伸得更远，即使抓同一个物体，保持姿态所需的关节转矩通常也更大。

## 概念追问

导师：本题中，2 N·m 的外力矩与 2 N·m 的支撑反力矩同时存在，为什么支架没有转动？

学生：

> 因为固定端A点为支架提供了逆时针的反力矩

反馈：正确识别反力矩方向。完整条件是两个力矩大小相等、方向相反，合力矩为零；支架原本静止，所以保持不转动。

## 当前学习判断

- 已展示：重力换算、简单垂直力臂下的力矩计算、加长支架对载荷的影响。
- 经纠正与追问：理解固定端反力矩抵消外力的转动效果。
- 后续继续巩固：力与力矩的单位、反力方向、主动说出“大小相等、方向相反”。
- 尚未考察：斜向力、非固定支撑、多载荷、支架自重、重心、材料强度和动态工况。

允许进入下一单元，不将本次表现等同于全面掌握静力学。

# 第 02 单元：支架自重与重心

状态：**已完成**（2026-11-16）。作答与概念解释反馈见 [第二课反馈](https://github.com/Zakariyya/cad-teacher/blob/main/learning/lesson-02-review.md)。作答记录见 [反馈](https://github.com/Zakariyya/cad-teacher/blob/main/learning/lesson-02-review.md)。

## 学习目标与前置知识

承接 [第一课](https://github.com/Zakariyya/cad-teacher/blob/main/learning/lesson-01.md) 的重力 `W=mg`、力矩 `M=Fd⊥` 和固定端平衡。学完应能区分质量（kg）、重力（N）、力矩（N·m），解释均匀杆重心在中点，计算含自重的支撑反力与反力矩，并正确标注方向。

## 1. 支架为什么会自己产生力矩？

工业机器人上的水平相机支架，即使没安装相机，支架自身也会受到向下的重力。只要重力的作用线与固定端 A 有水平距离，重力就会使支架产生顺时针转动趋势。

在本课近似**均匀重力场**中，刚体的重力可以等效集中作用在一个位置——**重心 G**；此时重心与质量中心重合。重心是位置，不是额外的一股力。

对**等截面且材料密度均匀**的直杆，左右两半关于中点对称，左右各小块质量在中点两侧的力矩相互抵消，所以 `x_G=L/2`。有缺口、凸台或质量偏置的真实支架，不能直接套用这一结论。

## 2. 工程对象、已知、假设与受力图

示例：左端 A 固定的水平相机支架，支架自身质量 `m_b=0.6 kg`，长度 `L=0.30 m`，末端相机质量 `m_c=2.0 kg`，其重心距 A 水平距离 `x_c=0.30 m`。教学近似 `g=10 m/s²`。

假设：支架均匀、足够刚、静止，连接为理想固定支撑；只看平面受力，忽略附件质量、弹性、加速度、振动和冲击。**研究对象仅为支架**，相机对它施加向下的力。

正方向：向右为 +x，向上为 +y，**逆时针力矩为正**。

![支架自重与重心的受力图](https://github.com/Zakariyya/cad-teacher/blob/main/learning/lesson-02-fbd.svg)

## 3. 示例计算：重量、重心、力臂

先把质量换成重力，再选 A 点计算力矩。由于本例杆水平、重力竖直，重力作用线到 A 的垂直距离就是对应水平位置。

```text
支架重心位置：x_G = L/2 = 0.15 m
支架自重：    W_b = m_b × g = 0.6 × 10 = 6 N（向下）
相机重量：    W_c = m_c × g = 2.0 × 10 = 20 N（向下）

支架自重力矩：M_b = 6 × 0.15 = 0.9 N·m（顺时针）
相机重力力矩：M_c = 20 × 0.30 = 6 N·m（顺时针）
```

不能把支架自重既作为分布载荷又作为集中力重复加入；用集中力 `W_b` 是在**本例静力平衡**中把分布重力等效到重心。

## 4. 固定端如何保持静止？

```text
ΣF_x = A_x = 0
ΣF_y = A_y - 6 - 20 = 0
       A_y = 26 N（向上）

ΣM_A = M_A - 6×0.15 - 20×0.30 = 0
       M_A = 6.9 N·m（逆时针）
```

第一课忽略自重时，`A_y=20 N`、`M_A=6 N·m`。加上支架自重后反力增加 6 N，反力矩增加 0.9 N·m，也就是多出 15%。**向下的是重力，不是力矩；力矩应该描述顺时针或逆时针。**

[示例计算脚本](https://github.com/Zakariyya/cad-teacher/blob/main/learning/lesson-02.py) 使用 Python 标准库，检查平衡残差、无自重极限，并用 1000 个微小杆段独立核对自重力矩。[验证记录](https://github.com/Zakariyya/cad-teacher/blob/main/learning/lesson-02-verification.md)。脚本**只计算上述公开示例，不包含练习答案**。

## 5. 与实际 CAD 支架的关系

你之前设计过含底板、凸台和孔的 `bracket_v2.py`。这种非均匀形状可能有偏心重心；真实质量和重心需要最终几何与材料密度数据，不能直接套用 `L/2`。多部分可用：

```text
m_i = ρ_i × V_i
x_G = (Σ m_i × x_i) / (Σ m_i)
```

其中密度 `ρ_i` 单位 kg/m³，体积 `V_i` 单位 m³，质量 `m_i` 单位 kg。孔是从实体中减去的体积。对 CAD 布尔后几何，应从最终实体求质量属性，避免重复计数。**本课没有读取或计算真实 bracket_v2 的质量属性**，也不能据此证明结构强度、刚度或装配可靠性。

````python
"""Lesson 02 teaching example: uniform horizontal bracket self-weight.

All inputs use SI units: kg, m, m/s^2. Outputs: N, N*m.
This script contains ONLY the published example, not exercise answers.
Ideal static rigid cantilever; no CAD, FEA, or physical verification.
"""

import json
from math import isclose


def bracket_example(bracket_mass_kg, length_m, camera_mass_kg, camera_x_m, g_m_s2=10.0):
    """Return the uniform-bracket center of mass and fixed support reactions."""
    if bracket_mass_kg < 0 or camera_mass_kg < 0 or length_m <= 0:
        raise ValueError('Masses must be nonnegative and length must be positive')
    if not 0 <= camera_x_m <= length_m or g_m_s2 <= 0:
        raise ValueError('Camera must lie on the bracket and g must be positive')

    bracket_cg_x_m = length_m / 2
    bracket_weight_N = bracket_mass_kg * g_m_s2
    camera_weight_N = camera_mass_kg * g_m_s2
    support_Ry_N = bracket_weight_N + camera_weight_N
    support_MA_Nm = bracket_weight_N * bracket_cg_x_m + camera_weight_N * camera_x_m
    # Positive force: upward; positive moment about A: counterclockwise.
    residual_Fy_N = support_Ry_N - bracket_weight_N - camera_weight_N
    residual_MA_Nm = (support_MA_Nm - bracket_weight_N * bracket_cg_x_m
                      - camera_weight_N * camera_x_m)
    assert isclose(residual_Fy_N, 0, abs_tol=1e-12)
    assert isclose(residual_MA_Nm, 0, abs_tol=1e-12)
    return {
        'bracket_cg_x_m': bracket_cg_x_m,
        'bracket_weight_N': bracket_weight_N,
        'camera_weight_N': camera_weight_N,
        'support_Ry_up_N': support_Ry_N,
        'support_MA_ccw_Nm': support_MA_Nm,
        'residual_Fy_N': residual_Fy_N,
        'residual_MA_Nm': residual_MA_Nm,
    }


def independent_distributed_moment_Nm(mass_kg, length_m, g_m_s2=10.0, slices=1000):
    """Midpoint integration of uniform self-weight as independent check."""
    if slices < 1 or length_m <= 0 or mass_kg < 0 or g_m_s2 <= 0:
        raise ValueError('Invalid distributed-load inputs')
    piece_weight_N = mass_kg * g_m_s2 / slices
    return sum(piece_weight_N * (i + 0.5) * length_m / slices
               for i in range(slices))


if __name__ == '__main__':
    demo = bracket_example(0.6, 0.30, 2.0, 0.30)
    expected = {
        'bracket_cg_x_m': 0.15,
        'bracket_weight_N': 6.0,
        'camera_weight_N': 20.0,
        'support_Ry_up_N': 26.0,
        'support_MA_ccw_Nm': 6.9,
    }
    for key, value in expected.items():
        assert isclose(demo[key], value, abs_tol=1e-12), (key, demo[key])
    integral = independent_distributed_moment_Nm(0.6, 0.30)
    assert isclose(integral, 0.9, abs_tol=1e-12), integral
    # With massless bracket, recover the lesson-01 external load result.
    no_self_weight = bracket_example(0, 0.30, 2.0, 0.30)
    assert isclose(no_self_weight['support_MA_ccw_Nm'], 6.0, abs_tol=1e-12)
    # With no camera, only the bracket's weight remains.
    no_camera = bracket_example(0.6, 0.30, 0, 0.30)
    assert isclose(no_camera['support_MA_ccw_Nm'], integral, abs_tol=1e-12)
    print(json.dumps({'example': demo,
                      'self_weight_moment_midpoint_Nm': integral,
                      'checks': 'PASS: equilibrium, midpoint integral, zero-mass limits'},
                     ensure_ascii=False, indent=2))
    print('Units: kg*m/s^2 = N; N*m = moment. No Pint-based unit checking.')
````

## E. 力矩为什么与力臂成正比：学习者的概念解释

### 学习者原话

> 其实就是杠杆原理，你把相机和支架理解成一个整体的话，相机离固定端越远，它们整体的中心就越偏离，这时候力矩平衡差值就出现了，至于为什么力矩和距离成正比，我发现我用语言解释不出来，你可以解释下，然后就可以结束第二课了，这个知识点我感觉我是学会了的

### 导师反馈与补充

整体理解正确：把支架和相机作为一个系统，系统总重力可以等效作用于整体重心。相机向外移动时，整体重心向外移动，因此总重力对固定端 A 的力矩增大。静止时固定端必须提供大小相等、方向相反的反力矩。更准确地说，不是静止状态下存在未平衡的“力矩差值”；而是外载荷产生更大的顺时针力矩，固定端用更大的逆时针反力矩抵消它。

用本题数据验证整体重心的说法：

- 支架质量 0.6 kg，重心位置 0.20 m；相机质量 1.5 kg。
- 相机位于 0.10 m 时，整体重心为
  `x_G=(0.6×0.20+1.5×0.10)/(0.6+1.5)=0.1286 m`，总重力 21 N，对 A 的力矩为约 2.7 N·m。
- 相机位于 0.35 m 时，整体重心为
  `x_G=(0.6×0.20+1.5×0.35)/(0.6+1.5)=0.3071 m`，总重力 21 N，对 A 的力矩为约 6.45 N·m。

为什么力矩与距离成正比：对垂直于力臂的力，物体绕转轴转过同一个小角度 `θ` 时，施力点走过的弧长为 `s=rθ`。同样的力沿运动方向做功 `W=Fs=Frθ`。因此每单位转角对应的功（力矩）为 `W/θ=Fr`。力不变时，力臂加倍，力矩也加倍。若力与位置向量不垂直，则只有垂直于力臂的分力产生该转动效果，一般关系为 `τ=rF sin(θ)`。

扳手/门把手是直观例子：用相同的力，离转轴越远，作用效果越大。学习者已理解杠杆关系；导师补充了比例关系的物理推导。

## 1. 为什么多个载荷必须一起计算？

想象一根固定在墙上的相机支架：

- 支架本身有重量；
- 相机有重量；
- 相机旁边还有一个传感器；
- 以后还可能夹着工件。

每个重量都会向下拉支架。它们会共同造成两种效果：

- **向下的总力**：所有向下的重量加在一起；
- **绕固定端转动的趋势**：每个重量按自己的位置产生力矩，再把这些力矩相加。

这里有一个关键点：**力可以直接按方向相加；力矩必须连同各自的力臂一起计算，不能只把力加起来就随便乘一个距离。**

## 2. 先明确研究对象与模型

本课例题只研究支架本体。相机和传感器不画成独立刚体，而是把它们对支架的作用等效为各自位置处的向下重力。

已知：

- 水平支架左端 A 与墙体理想固定；
- 支架长度 L = 0.60 m，质量 mᵦ = 0.8 kg，假设均匀；
- 相机质量 m𝚌 = 1.5 kg，重心距 A 为 0.50 m；
- 传感器质量 mₛ = 0.5 kg，重心距 A 为 0.60 m；
- 取 g = 10 m/s²，结构静止。

假设与边界：

- 支架足够刚，处于静止状态，做二维平面静力分析；
- 支架均匀，因此支架重心在中点 0.30 m；
- 所有重力竖直向下，没有水平外载；
- 忽略线缆拉力、紧固件自重、弹性变形、振动、冲击和加速度；
- 固定端能够提供水平反力、竖直反力和反力矩。

这只是理想刚体静力估算，不是支架强度或安全性验收。

## 3. 受力图：先把所有力画全

![多载荷支架自由体图](https://github.com/Zakariyya/cad-teacher/blob/main/learning/lesson-03-fbd.svg)

约定：

- 向右为 +x，向上为 +y；
- 逆时针力矩为正，顺时针力矩为负；
- Aₓ、Aᵧ 是固定端反力，Mₐ 是固定端反力矩；
- Wᵦ、W𝚌、Wₛ 分别是支架、相机、传感器的重力。

**为什么 A 点有三个反力未知量？** 因为理想固定端既阻止水平移动，也阻止竖直移动，还阻止支架转动，所以要用 Aₓ、Aᵧ、Mₐ 描述它的约束作用。这是第一课学过的固定支撑模型。

## 4. 把每个载荷变成力和力矩

先算重量：

**W = m × g**

| 载荷 | 质量 | 重力 | 作用位置 |
|---|---:|---:|---:|
| 支架自重 | 0.8 kg | 8 N，向下 | 0.30 m |
| 相机 | 1.5 kg | 15 N，向下 | 0.50 m |
| 传感器 | 0.5 kg | 5 N，向下 | 0.60 m |

对于本题，支架水平、重力竖直，因此每个重力的垂直力臂就是它到 A 点的水平距离。

**M = F × d**

逐个计算对 A 点的力矩：

| 载荷 | 计算 | 力矩方向 |
|---|---:|---|
| 支架自重 | 8 × 0.30 = 2.4 N·m | 顺时针 |
| 相机 | 15 × 0.50 = 7.5 N·m | 顺时针 |
| 传感器 | 5 × 0.60 = 3.0 N·m | 顺时针 |

因此外载荷产生的顺时针力矩总和为 2.4 + 7.5 + 3.0 = 12.9 N·m。

注意：**三个力的大小不能直接相加后，再分别乘三个不同的距离。** 必须逐个求力矩再求和；或者先求出整体重心，再把总重力等效作用在整体重心上。这两种算法结果相同，不能重复计算。

## 5. 写出三个平衡条件

静止的二维刚体必须同时满足：

- 水平方向不平移：ΣFₓ = 0
- 竖直方向不平移：ΣFᵧ = 0
- 不绕平面内任何点转动：ΣM = 0

本题选择 A 点作为取矩点，并约定逆时针为正。

### 第一步：水平方向

没有水平外载，所以：

**ΣFₓ = Aₓ = 0**

### 第二步：竖直方向

向上为正，三个重力向下：

**ΣFᵧ = Aᵧ − 8 − 15 − 5 = 0**

所以固定端需要提供向上的竖直反力，大小等于三个向下重量之和。

### 第三步：绕 A 点的力矩

三个重力都使支架顺时针转动，因此它们在方程中为负；固定端反力矩必须逆时针：

**ΣMₐ = Mₐ − 8 × 0.30 − 15 × 0.50 − 5 × 0.60 = 0**

因此：

**Mₐ = 8 × 0.30 + 15 × 0.50 + 5 × 0.60 = 12.9 N·m**

### 为什么选 A 点取矩？

Aₓ 和 Aᵧ 的作用线都经过 A 点，对 A 的力臂为零，因此它们不会出现在绕 A 点的力矩方程里。这样就能先求出固定端需要抵抗的转动效果。

**取矩点可以选其他位置；静力平衡时，绕任意点的合力矩都为零。** 初学时优先选择未知反力通过的点，通常最省事。

## 6. 用整体重心再理解一次

这和第二课直接衔接。三个重力都在同一个均匀重力场中，因此可以把它们等效为一个总重力，作用在整体重心：

**xＧ = (8 × 0.30 + 15 × 0.50 + 5 × 0.60) ÷ (8 + 15 + 5)**

**xＧ ≈ 0.4607 m**

总重力为三个重量之和，作用在距 A 约 0.4607 m 的位置。用总重力乘这个位置，会得到与逐个求力矩相同的结果。

两种方法怎么选：

- **逐个求力矩**：更适合载荷多、位置不同、方向可能不同的结构，最不容易漏项。
- **整体重心法**：适合多个平行重力载荷，能帮助你理解系统整体的重心位置。

````python
"""Lesson 03: multi-load static equilibrium worked-example check.

Educational model only: a horizontal rigid cantilever, fixed at A, with
three vertical downward gravity loads. SI units; CCW support moment is positive.
"""
from math import isclose

G_M_S2 = 10.0
loads = [
    {"name": "bracket self-weight", "mass_kg": 0.8, "x_m": 0.30},
    {"name": "camera", "mass_kg": 1.5, "x_m": 0.50},
    {"name": "sensor", "mass_kg": 0.5, "x_m": 0.60},
]

for load in loads:
    load["weight_N"] = load["mass_kg"] * G_M_S2
    load["clockwise_moment_Nm"] = load["weight_N"] * load["x_m"]

total_downward_N = sum(load["weight_N"] for load in loads)
total_clockwise_Nm = sum(load["clockwise_moment_Nm"] for load in loads)

# Equilibrium: Ay balances all downward loads; MA balances all clockwise moments.
Ay_N = total_downward_N
MA_Nm = total_clockwise_Nm
x_combined_cg_m = total_clockwise_Nm / total_downward_N

residual_Fy_N = Ay_N - total_downward_N
residual_MA_Nm = MA_Nm - total_clockwise_Nm

assert isclose(total_downward_N, 28.0, abs_tol=1e-12)
assert isclose(total_clockwise_Nm, 12.9, abs_tol=1e-12)
assert isclose(x_combined_cg_m, 0.4607142857142857, abs_tol=1e-12)
assert isclose(residual_Fy_N, 0.0, abs_tol=1e-12)
assert isclose(residual_MA_Nm, 0.0, abs_tol=1e-12)

print("Loads:")
for load in loads:
    print(
        f"{load['name']}: W={load['weight_N']:.1f} N, "
        f"x={load['x_m']:.2f} m, "
        f"M_A={load['clockwise_moment_Nm']:.2f} N·m clockwise"
    )
print(f"Total downward force = {total_downward_N:.1f} N")
print(f"Fixed support reaction Ay = {Ay_N:.1f} N upward")
print(f"Fixed support reaction moment MA = {MA_Nm:.2f} N·m counterclockwise")
print(f"Equivalent combined CG x_G = {x_combined_cg_m:.4f} m from A")
print(f"Equilibrium residuals: ΣFy={residual_Fy_N:.1f} N, ΣM_A={residual_MA_Nm:.1f} N·m")
````

# 第 03 单元：多载荷平衡——作答与反馈

记录日期：2026-11-17。题目见 [第三课讲义](https://github.com/Zakariyya/cad-teacher/blob/main/learning/lesson-03.md)。保留学习者原答，再区分数值、单位、方向和概念理解。

## A. 基础题

### 学习者原答

> 1、6n，中心（0.25m）
> 2、支架1.5n，p1:2n, p2:3.6n,方向都是顺时针向下
> 3、6+10+8=24n
> 4、1.5+2+3.6=7.1n
> 5、竖直平衡就是他们三个竖直反力加起来，力矩平衡就是逆时针向上力矩加起来

### 逐项反馈

1. **正确。** 支架重量为 0.6 × 10 = 6 N，均匀支架的重心在中点 0.50 / 2 = 0.25 m。
2. **数值正确，方向表述需要分开。** 支架重力 6 N 向下，对 A 点产生 1.5 N·m 顺时针力矩；P1 为 10 N 向下，产生 2.0 N·m 顺时针力矩；P2 为 8 N 向下，产生 3.6 N·m 顺时针力矩。“向下”描述力的方向；“顺时针”描述力矩方向。
3. **正确。** 固定端竖直反力为 6 + 10 + 8 = 24 N，方向向上。
4. **数值正确，单位和方向需要补齐。** 外载总力矩为 7.1 N·m，顺时针；固定端反力矩为 7.1 N·m，逆时针。力矩单位是 N·m，不是 N。
5. **概念方向正确，但方程表述不够准确。** 不是把“三个竖直反力加起来”，而是把所有竖直外力与支撑反力按正负号相加；力矩也要把顺、逆时针按符号相加。

平衡方程（向上为正、逆时针为正）：

`ΣFy = Ay - 6 - 10 - 8 = 0`

`ΣMA = MA - 6 × 0.25 - 10 × 0.20 - 8 × 0.45 = 0`

因此 Ay = 24 N 向上，MA = 7.1 N·m 逆时针。

## B. 工程应用题：机械臂末端多个部件

### 学习者原答

> 支架自身重心是长度减半，支架、相机、传感器重量都是质量成加速度，A的竖直反力是他们三的重力重量的和，反力矩是各自重力乘以距离A点的距离（支架则是乘以重心距离a点的距离）。
>
> 对a点产生力矩最大的部件取决于各自产生的力矩数值，不能只看质量是因为力矩跟距离固定点距离挂钩。第四题固定端力矩变小，竖直反力不变，因为竖直反力只跟重量和重力加速度挂钩，重力加速度是固定值，期间物品重量不变

### 反馈

四个物理判断均正确，说明已经理解多部件重量与力臂如何共同决定固定端反力和反力矩。

| 部件 | 重量 | 作用位置 | 对 A 点的顺时针力矩 |
|---|---:|---:|---:|
| 连杆自身 | 12 N | 0.40 m | 4.80 N·m |
| 相机 | 20 N | 0.70 m | 14.00 N·m |
| 传感器 | 5 N | 0.25 m | 1.25 N·m |
| 工件 | 10 N | 0.80 m | 8.00 N·m |
| **合计** | **47 N** | — | **28.05 N·m** |

因此固定端竖直反力为 47 N、向上；固定端反力矩为 28.05 N·m、逆时针。相机产生的力矩最大，为 14 N·m。

相机从 0.70 m 移到 0.40 m：

`ΔM = 20 × (0.70 - 0.40) = 6 N·m`

固定端需要抵抗的反力矩减少 6 N·m；竖直反力不变，仍为 47 N。

用词补充：重量是质量乘当地重力加速度 g，即 W = mg。本题按题设取 g = 10 m/s²。

本题按学习者要求以定性解释为主，没有要求其补交工程题的完整数值推导；表格数值由导师核算，不能记为学习者独立完成的数值计算。

# 第 04 单元：力分解与斜向载荷

状态：**讲解、示例与练习已发布；等待学习者作答**（2026-11-17）。不要提前公开练习答案。

## 1. 学习目标与前置知识

承接第三课「多载荷平衡」。本课开始处理不再竖直或水平的力。学完应能：

1. 识别斜向力的角度是相对水平线还是竖直线测量。
2. 用直角三角形把一个斜向力分解为水平、竖直两个分量。
3. 根据力的实际指向给分量添加正负号。
4. 将力分量代入静力平衡方程，求出固定端反力和反力矩。
5. 判断某个分力是否产生力矩，而不是误以为所有分力都会产生力矩。

前置知识：正交的水平/竖直方向、固定端三个反力未知量、第三课的多载荷平衡。三角函数只补本课需要的部分，不要求先学完整三角学。

## 2. 为什么机器人结构中会出现斜向力？

机械臂夹爪抓住工件时，接触力不一定竖直向下；拉索、斜撑、倾斜连杆、斜面接触也会把力沿倾斜方向传递。

如果一股力既向左又向下，我们不能直接把它和纯水平力或纯竖直力相加。要先把它换成两个互相垂直的分量：

- 水平分量：描述这股力在水平方向上的效果。
- 竖直分量：描述这股力在竖直方向上的效果。

**分量不是多出来的两股真实载荷。** 它们是同一个斜向力的数学表示，两个分量合起来，效果与原来的斜向力完全相同。不要把原力和两个分量重复相加。

## 3. 先认识直角三角形：sin 和 cos 怎么用？

假设角度 θ 是从水平线量起：

- 斜边是原来的力 F；
- 邻边是水平分量 Fx；
- 对边是竖直分量 Fy 的大小。

因此：

`Fx = F cos θ`

`|Fy| = F sin θ`

记忆方法：

- **cos：角度旁边那条边**，本题就是水平分量。
- **sin：角度对面那条边**，本题就是竖直分量。

如果角度是从竖直线量起，水平与竖直分量对应的 sin/cos 就要交换。不要只背公式，先看角度画在哪一侧。

### 方向和正负号

本课程继续约定：向右为 +x，向上为 +y。

| 分量方向 | 符号 |
|---|---:|
| 向右 | +Fx |
| 向左 | −Fx |
| 向上 | +Fy |
| 向下 | −Fy |

例如，一股力朝右下方：水平分量为正，竖直分量为负。**sin 和 cos 只给分量大小；方向正负要根据箭头判断。**

### 用 3-4-5 三角形先算一次

如果一个 100 N 的斜向力形成 3-4-5 直角三角形：

- 水平边占斜边的 3/5，所以水平分量大小为 100 × 3/5 = 60 N；
- 竖直边占斜边的 4/5，所以竖直分量大小为 100 × 4/5 = 80 N。

这个角度约为 53.13°（从水平线量起），所以 cosθ = 0.6、sinθ = 0.8。这样可以先理解分量关系，不必一上来就死记小数。

本图中的斜向外力为 100 N，作用在水平连杆末端，方向向右下方。它可以表示为向右 60 N、向下 80 N 两个分量。连杆自身重力 10 N 作用在中点。

## 5. 完整例题：固定端支架受到斜向力

### 已知与模型

一根水平刚性连杆左端 A 固定，长度 L = 0.60 m，自身质量 1.0 kg，质量均匀。末端受到 100 N 的斜向力，方向为**水平线以下 53.13°、向右下方**。取 g = 10 m/s²。

假设：二维静力平衡；连杆足够刚；力作用在连杆中心线末端；忽略连接件、线缆自重、变形、振动与冲击。

### 第一步：先分解斜向力

3-4-5 比例给出：

- Fx = +100 × 3/5 = +60 N，向右；
- Fy = −100 × 4/5 = −80 N，向下。

这里负号很重要：竖直分量向下。

### 第二步：计算连杆自重

连杆重量 W = 1.0 × 10 = 10 N，向下。均匀连杆的重心在中点，距 A 为 0.30 m。

### 第三步：列水平方向平衡

`ΣFx = Ax + 60 = 0`

所以 Ax = −60 N，也就是固定端提供 60 N 向左的水平反力。

### 第四步：列竖直方向平衡

`ΣFy = Ay − 80 − 10 = 0`

所以 Ay = 90 N，方向向上。

### 第五步：绕 A 点取力矩

约定逆时针为正。末端的 80 N 向下分量使连杆顺时针转动；连杆自重也使它顺时针转动。

`ΣMA = MA − 80 × 0.60 − 10 × 0.30 = 0`

所以固定端反力矩为 51 N·m，逆时针。

**为什么 60 N 的水平分量没有出现在这道力矩方程中？** 因为它的作用线沿着水平连杆中心线，经过 A 点，垂直力臂为零。它仍然会影响水平反力 Ax。

注意：这不代表水平分力永远不会产生力矩。如果力的作用线与 A 点有垂直偏距，它同样可能产生力矩。判断时看的是“力的作用线到取矩点的垂直距离”，而不是只看力的名称。

## 6. 本课最容易犯的五个错误

1. **sin/cos 用反：** 先确认角度从水平还是竖直量起，再找邻边和对边。
2. **只算绝对值：** 斜向力向左、向右、向上、向下，分量的正负号不能省略。
3. **重复计算：** 原斜向力与它的两个分量不能同时放进同一个平衡方程。
4. **认为水平分力一定没有力矩：** 只有它的作用线经过取矩点时，力臂才为零。
5. **把力矩单位写成 N：** 力用 N，力矩用 N·m。

## 7. 基础练习：相机支架受到斜向外力

水平支架左端 A 固定，长度 0.50 m，自身质量 0.4 kg，质量均匀。末端受到 50 N 的力，方向为**水平线以下 30°、向右下方**。取 g = 10 m/s²。可使用 sin30° = 0.5、cos30° ≈ 0.866。

请回答：

1. 将 50 N 斜向力分解成 Fx、Fy，分别写出大小、正负号和方向。
2. 支架自重是多少？作用点在哪里？
3. 求固定端 Ax、Ay，注明方向。
4. 求固定端反力矩 MA，注明方向与 N·m 单位。
5. 写出 ΣFx = 0、ΣFy = 0、ΣMA = 0 三个平衡方程。

## 8. 工程应用：机械臂夹爪承受斜向接触力

一根水平机械臂连杆左端 A 固定，长度 0.70 m，自身质量 1.0 kg，质量均匀。末端夹爪与工件接触，工件对夹爪施加一个 80 N 的力，方向为**水平线以下 30°、向左下方**。取 g = 10 m/s²。

请回答：

1. 将 80 N 分解为水平和竖直分量，注明方向和正负号。
2. 求连杆自重及其重心位置。
3. 求 A 点的水平反力、竖直反力和反力矩。
4. 如果同一个 80 N 力的方向不变，但作用点从 0.70 m 移到 0.35 m，哪些反力会变化？反力矩变化多少？解释原因。

## 9. 本课结束后应具备的能力

能把一个斜向外力转成水平、竖直分量，正确添加符号，并与其他载荷一起写进平衡方程。后续的斜拉索、斜撑、斜面接触、夹爪摩擦和机械臂关节载荷都会用到这一能力。

**本课仍然是二维、静止、刚体模型。** 还没有分析铰支撑、滚动支撑、摩擦、材料应力或动态加速度；不要把本课反力结果直接当成实机选型或安全验收结论。

````python
"""Lesson 04: resolve an oblique force and check fixed-support equilibrium.

Educational model only: a horizontal rigid cantilever fixed at A.
A 100 N force acts at the free end, 53.1301 degrees below +x.
SI units; right/up positive; counterclockwise moments positive.
"""
from math import atan2, cos, degrees, isclose, sin

G_M_S2 = 10.0
L_M = 0.60
BEAM_MASS_KG = 1.0
FORCE_N = 100.0

# A 3-4-5 triangle: cos(theta)=3/5, sin(theta)=4/5.
theta_rad = atan2(4.0, 3.0)
theta_deg = degrees(theta_rad)
Fx_N = FORCE_N * cos(theta_rad)          # right, positive
Fy_N = -FORCE_N * sin(theta_rad)         # down, negative
beam_weight_N = BEAM_MASS_KG * G_M_S2
beam_cg_x_m = L_M / 2.0

# Fixed-support reactions make the total force and moment zero.
Ax_N = -Fx_N
Ay_N = beam_weight_N - Fy_N
# The horizontal component is collinear with the beam centreline and A.
horizontal_component_moment_Nm = 0.0
MA_Nm = -(L_M * Fy_N + beam_cg_x_m * (-beam_weight_N))

residual_Fx_N = Ax_N + Fx_N
residual_Fy_N = Ay_N + Fy_N - beam_weight_N
residual_MA_Nm = MA_Nm + L_M * Fy_N - beam_cg_x_m * beam_weight_N

assert isclose(theta_deg, 53.13010235415598, abs_tol=1e-10)
assert isclose(Fx_N, 60.0, abs_tol=1e-12)
assert isclose(Fy_N, -80.0, abs_tol=1e-12)
assert isclose(beam_weight_N, 10.0, abs_tol=1e-12)
assert isclose(Ax_N, -60.0, abs_tol=1e-12)
assert isclose(Ay_N, 90.0, abs_tol=1e-12)
assert isclose(MA_Nm, 51.0, abs_tol=1e-12)
assert isclose(horizontal_component_moment_Nm, 0.0, abs_tol=1e-12)
assert isclose(residual_Fx_N, 0.0, abs_tol=1e-12)
assert isclose(residual_Fy_N, 0.0, abs_tol=1e-12)
assert isclose(residual_MA_Nm, 0.0, abs_tol=1e-12)

print(f"Force angle = {theta_deg:.4f} degrees below +x")
print(f"Applied force = {FORCE_N:.1f} N down-right")
print(f"Fx = {Fx_N:.1f} N right; Fy = {abs(Fy_N):.1f} N down")
print(f"Beam self-weight = {beam_weight_N:.1f} N at x = {beam_cg_x_m:.2f} m")
print(f"Fixed support Ax = {Ax_N:.1f} N (left)")
print(f"Fixed support Ay = {Ay_N:.1f} N (up)")
print(f"Fixed support MA = {MA_Nm:.2f} N·m (counterclockwise)")
print("Horizontal force component moment about A = 0 N·m (line of action passes through A)")
print(f"Equilibrium residuals: Fx={residual_Fx_N:.1f} N, Fy={residual_Fy_N:.1f} N, MA={residual_MA_Nm:.1f} N·m")
````

# 教材质量与证据标准

## 每课必须具备

学习目标和前置知识；真实机器人对象；物理意义；研究对象与模型；已知和参数来源；假设及其影响；图示；符号、单位、方向；从公式到代入的示例；一道基础题和一道工程题；学生原答与针对性反馈；实际执行证据；本课作用、未解问题和下一步。

来源必须指到具体 Skill 文件/参考文件/脚本及固定版本。脚本内容是可检查的实现，不能因为来自 Skill 就视为正确结论。工程数值应做单位、数量级、极限工况和独立简式检查。

## 分清四类验证

| 类别 | 示例 | 证明范围 |
| --- | --- | --- |
| 几何验证 | 包围盒、孔径、干涉、模型有效性 | 形状与尺寸符合当前几何模型 |
| 力学估算 | 刚体平衡、梁公式、转矩初估 | 指定假设下的载荷或响应估计 |
| 仿真验证 | FEA 网格收敛、动力学求解、控制仿真 | 指定边界、材料、求解器与模型中的数值结果 |
| 实物验证 | 量具、载荷试验、编码器与电流实测 | 特定设备、工况和测量不确定度下的实测表现 |

算术检查是计算内部一致性检查，不自动升级为力学模型、仿真或实物验证。每类分别记录“已执行/未执行/受阻”，不以一个总 PASS 代替证据。

## 能力递进与纠错

第一层：能解释物理意义；第二层：能画图并选择模型；第三层：能列式、计算、检查；第四层：能在条件改变时重新判断；第五层：能用仿真和实测校正模型。课程完成由这些可观察证据决定，不按聊天次数判断。

学生算对但单位或方向错，要分别纠正。记录真实表达，不替学生补写“已经理解”的答案。允许先进入下一课，再用变化题回访弱点。重要公式的纠错应同时更新讲义、答案、脚本和学习包，提交信息说明修正原因。

## 长期内容边界

“从入门到精通”是培养目标，不是质量认证。真实机器人设计还需要制造、电气、控制、调试与现场经验。电路接线、驱动参数和实机试验以具体设备手册为准；教材中的教学近似不直接作为实机验收标准。

Skill 不能覆盖完整的电路、控制理论和 ROS 2 课程。涉及版本行为、产品参数、标准和安全边界时，补查对应官方来源并记录日期，避免从机械工具推导不存在的能力。

name: mechanics-visuals
description: Produces clean, correct mechanics teaching figures — Mohr's circle, shear/moment/deflection diagrams, S–N curves, stress–strain curves, and free-body diagrams — as PNG/SVG for slides, notes, or exams. Use when the user asks to draw, plot, or visualize a mechanics concept, an FBD, a beam diagram, or a stress state.
---

# Mechanics Visuals

The numbers behind every figure come from `scripts/mech_plots.py`, so the picture and the values always agree.

## Workflow
1. **Pin down the scenario**: geometry, loads, supports, sign convention, and units. If the user is teaching, ask once which textbook's convention they follow (the default is Shigley/Hibbeler).
2. **Generate the figure:**
   ```bash
   python scripts/mech_plots.py mohr --sx 80 --sy -40 --txy 30 --out mohr
   python scripts/mech_plots.py beam --L 2000 --support simply --point 800:5000 --udl 0:2000:2 --I 8.3e6 --out beam
   python scripts/mech_plots.py sn   --Sut 690 --Se 280 --out sn
   python scripts/mech_plots.py ss   --sy 350 --Sut 480 --n 0.18 --out ss
   ```
3. **Free-body diagrams**: no script. Write a matplotlib or SVG drawing following `references/fbd_style.md` (body as a light-grey shape, every force as a labelled arrow from its point of application, reactions in a different color, coordinate triad in a corner). Check equilibrium numerically (ΣF = 0, ΣM = 0) and print the residuals before you show the figure.
4. **Verify**: compare one value against a closed form, e.g. simply supported center load M_max = PL/4, δ = PL³/48EI. State the comparison.
5. **Deliver**: the PNG for viewing, the SVG for slides, and a 2–3 sentence caption with the key numbers.

## Style
Use one accent color for loads, one for reactions and grey for geometry. Use SI units, label every axis, and keep titles under about 8 words. Never put more than one concept in a single figure unless the user asks for it.

## 源文件：resources/vendor/baratilab/skills/mechanics-visuals/references/fbd_style.md

# Free-body diagram style

- Isolate the body: draw it alone, with supports replaced by their reactions.
- Body: light grey fill `#d9dde3`, dark outline `#2c3e50`, 1.5 pt.
- Applied loads: `#c0392b` arrows; reactions: `#1f4e79` arrows; unknowns are labelled symbolically (A_x, A_y, M_A).
- Arrow tail or head sits on the point of application. Distributed loads are drawn as a row of arrows with an envelope line labelled w (N/m).
- Moments are drawn as a curved arrow with a label.
- Dimensions: thin grey lines with end ticks, placed below or outside the body.
- Coordinate triad in the lower left. State the positive sense of moment.
- Support → reaction mapping: pin → Ax, Ay; roller → one force normal to the surface; fixed → Ax, Ay, M; cable → tension along the cable; smooth contact → normal force.

Matplotlib snippet:
```python
from matplotlib.patches import FancyArrowPatch, Rectangle
ax.add_patch(Rectangle((0, 0), L, h, fc="#d9dde3", ec="#2c3e50", lw=1.5))
ax.add_patch(FancyArrowPatch((x, y + 0.6), (x, y), arrowstyle="-|>", mutation_scale=15, color="#c0392b", lw=1.8))
ax.text(x + 0.05, y + 0.65, "P = 5 kN", color="#c0392b")
ax.set_aspect("equal"); ax.axis("off")
```

## 源文件：resources/vendor/baratilab/skills/mechanics-visuals/scripts/mech_plots.py

````python
#!/usr/bin/env python3
"""Publication-quality mechanics teaching plots.

  mohr   --sx 80 --sy -40 --txy 30            (MPa)  2-D Mohr's circle + principal values
  beam   --L 2000 --support simply|cantilever --point 1000:5000 --udl 0:2000:3
                                                 shear / moment / deflection diagrams
  sn     --Sut 690 --Se 280 [--f 0.86]          S-N curve (Basquin, Shigley 10^3-10^6)
  ss     --E 205000 --sy 350 --Sut 480 --n 0.18 Ramberg-Osgood stress-strain curve
All write <out>.png (and .svg) and print key numbers as JSON.
"""
import argparse
import json
import math

import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
import numpy as np

BLUE, RED, GRAY = "#1f4e79", "#c0392b", "#7f8c8d"
plt.rcParams.update({"font.size": 10, "axes.spines.top": False, "axes.spines.right": False})


def save(fig, out):
    fig.tight_layout()
    fig.savefig(out + ".png", dpi=200)
    fig.savefig(out + ".svg")


def mohr(a):
    c = (a.sx + a.sy) / 2
    R = math.hypot((a.sx - a.sy) / 2, a.txy)
    s1, s2 = c + R, c - R
    thp = 0.5 * math.degrees(math.atan2(2 * a.txy, a.sx - a.sy))
    fig, ax = plt.subplots(figsize=(6, 6))
    t = np.linspace(0, 2 * np.pi, 400)
    ax.plot(c + R * np.cos(t), R * np.sin(t), color=BLUE)
    # Convention: plot (sx, -txy) as point X (cw shear positive, Shigley)
    X, Y = (a.sx, -a.txy), (a.sy, a.txy)
    ax.plot(*zip(X, Y), color=GRAY, ls="--")
    ax.plot(*X, "o", color=RED); ax.annotate(f"x ({a.sx}, {a.txy})", X, xytext=(6, -12), textcoords="offset points")
    ax.plot(*Y, "o", color=RED); ax.annotate(f"y ({a.sy}, {-a.txy})", Y, xytext=(6, 6), textcoords="offset points")
    for s, lab in ((s1, "σ₁"), (s2, "σ₂")):
        ax.plot(s, 0, "s", color=BLUE); ax.annotate(f"{lab} = {s:.1f}", (s, 0), xytext=(4, 8), textcoords="offset points")
    ax.plot(c, R, "^", color=BLUE); ax.annotate(f"τmax = {R:.1f}", (c, R), xytext=(4, 4), textcoords="offset points")
    ax.axhline(0, color="k", lw=0.6); ax.axvline(0, color="k", lw=0.6)
    ax.set_aspect("equal"); ax.set_xlabel("σ (MPa)"); ax.set_ylabel("τ (MPa, cw ↓)")
    ax.invert_yaxis()
    ax.set_title("Mohr's circle (plane stress)")
    save(fig, a.out)
    return {"center": c, "R": R, "sigma1": s1, "sigma2": s2, "tau_max_inplane": R,
            "theta_p_deg_ccw_from_x": thp,
            "tau_max_absolute": max(R, abs(s1) / 2, abs(s2) / 2)}


def beam(a):
    L, EI = a.L, a.E * a.I
    x = np.linspace(0, L, 2001)
    loads = []  # (type, params)
    for p in a.point or []:
        pos, P = map(float, p.split(":")); loads.append(("P", pos, P))
    for u in a.udl or []:
        x0, x1, w = map(float, u.split(":")); loads.append(("w", x0, x1, w))
    # Reactions
    Ptot = sum(l[2] for l in loads if l[0] == "P") + sum(l[3] * (l[2] - l[1]) for l in loads if l[0] == "w")
    Mo = sum(l[2] * l[1] for l in loads if l[0] == "P") + sum(l[3] * (l[2] - l[1]) * (l[1] + l[2]) / 2 for l in loads if l[0] == "w")
    if a.support == "simply":
        RB = Mo / L; RA = Ptot - RB; M0 = 0.0
    else:  # cantilever fixed at x=0
        RA = Ptot; M0 = -Mo; RB = 0.0
    V = np.full_like(x, RA); M = M0 + RA * x
    for l in loads:
        if l[0] == "P":
            V -= l[2] * (x >= l[1]); M -= l[2] * np.clip(x - l[1], 0, None)
        else:
            _, x0, x1, w = l
            seg = np.clip(x, x0, x1) - x0
            V -= w * seg
            M -= w * seg * (x - x0 - seg / 2)
    # Deflection: integrate M/EI twice, apply BCs
    th = np.concatenate([[0], np.cumsum((M[1:] + M[:-1]) / 2 * np.diff(x))]) / EI
    y = np.concatenate([[0], np.cumsum((th[1:] + th[:-1]) / 2 * np.diff(x))])
    if a.support == "simply":
        y -= y[-1] * x / L  # y(0)=y(L)=0
    fig, axs = plt.subplots(3, 1, figsize=(7, 7), sharex=True)
    for ax, data, lab, col in zip(axs, (V, M / 1e3, y), ("Shear V (N)", "Moment M (N·m)", "Deflection (mm)"), (BLUE, RED, GRAY)):
        ax.fill_between(x, data, color=col, alpha=0.25); ax.plot(x, data, color=col)
        ax.axhline(0, color="k", lw=0.6); ax.set_ylabel(lab)
    axs[-1].set_xlabel("x (mm)")
    axs[0].set_title(f"{'Simply supported' if a.support == 'simply' else 'Cantilever'} beam, L = {L:g} mm")
    save(fig, a.out)
    i = int(np.argmax(np.abs(M)))
    return {"RA_N": RA, "RB_N": RB, "M_fixed_Nmm": M0, "Mmax_Nmm": float(M[i]), "x_Mmax_mm": float(x[i]),
            "Vmax_N": float(np.max(np.abs(V))), "ymax_mm": float(y[np.argmax(np.abs(y))]),
            "sign_convention": "loads +down; deflection +up; sagging moment +"}


def sn(a):
    f = a.f
    a_ = (f * a.Sut) ** 2 / a.Se
    b = -math.log10(f * a.Sut / a.Se) / 3
    N = np.logspace(0, 8, 400)
    S = np.where(N < 1e3, a.Sut * N ** (math.log10(f) / 3),  # low-cycle line from Sut at N=1 to f*Sut at 1e3
                 np.where(N <= 1e6, a_ * N ** b, a.Se))
    fig, ax = plt.subplots(figsize=(7, 4.5))
    ax.semilogx(N, S, color=BLUE, lw=2)
    ax.axhline(a.Se, color=GRAY, ls="--"); ax.text(2e6, a.Se * 1.03, f"Se = {a.Se:g} MPa", color=GRAY)
    ax.axvline(1e3, color=GRAY, lw=0.5); ax.axvline(1e6, color=GRAY, lw=0.5)
    ax.set_xlabel("Cycles to failure N"); ax.set_ylabel("Fully reversed stress amplitude (MPa)")
    ax.set_title("S–N curve (steel, Basquin fit)")
    save(fig, a.out)
    return {"a_MPa": a_, "b": b, "S_at_1e3": f * a.Sut, "Se": a.Se}


def ss(a):
    s = np.linspace(0, a.Sut, 400)
    eps = s / a.E + 0.002 * (s / a.sy) ** (1 / a.n)
    fig, ax = plt.subplots(figsize=(7, 4.5))
    ax.plot(eps * 100, s, color=BLUE, lw=2)
    e_off = np.linspace(0.002, 0.002 + a.sy / a.E * 1.1, 50)
    ax.plot(e_off * 100, a.E * (e_off - 0.002), color=GRAY, ls="--", label="0.2% offset")
    ax.plot(eps[np.argmin(abs(s - a.sy))] * 100, a.sy, "o", color=RED); ax.annotate(f"σy = {a.sy:g}", (eps[np.argmin(abs(s - a.sy))] * 100, a.sy), xytext=(6, -12), textcoords="offset points")
    ax.set_xlabel("Strain (%)"); ax.set_ylabel("Stress (MPa)"); ax.legend()
    ax.set_title("Engineering stress–strain (Ramberg–Osgood)")
    save(fig, a.out)
    return {"strain_at_Sut": float(eps[-1]), "n": a.n}
````

# Worked Problem Generator

## Workflow
1. **Spec.** Get the topic, the learning objective, the level (intro undergrad / upper undergrad / grad / exec-ed practitioner), the count, the format (open-ended, multiple choice, or both), and the unit system. If the user gave a syllabus or lecture notes, align notation with them.
2. **Design each problem** against the template in `references/problem_template.md`:
   - a realistic context, ideally a real device or failure, in 2–4 sentences;
   - givens with units and realistic magnitudes (check them against `machine-element-sizing/references/materials.md` or CoolProp);
   - a clear ask, with sub-parts building from (a) a direct application to (c) a judgment or design decision;
   - mix the Bloom levels across the set: apply, analyze, evaluate, create.
3. **Solve in code first.** For each problem, write a short Python solution (use `pint` for units) and run it. The worked solution is written from the code output, so the text and the numbers can't disagree. Use the other skills' scripts where they fit.
4. **Write the worked solution**: FBD or schematic description (or a figure via `mechanics-visuals`) → assumptions → governing equations → substitution → answer boxed with units and 3 significant figures → a one-line sanity check (order of magnitude, limiting case) → common mistakes students make on this problem.
5. **Multiple-choice items.** Make distractors from real errors (a forgotten factor of 2, diameter used for radius, a unit slip, the wrong failure theory), each computed in code. Spread correct answers evenly across A/B/C/D.
6. **Exam variants** (when asked): parameterize the givens, generate N variants with seeded random values in realistic ranges, and recompute every answer key in code.
7. **Deliver.** For students, give the problem set without solutions plus a separate solutions document. For a quiz, use the quiz widget (or the format the user asks for). Include the solution scripts in an appendix for instructors.
