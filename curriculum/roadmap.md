这是逐课编写的培养路线，不是已完成的教材。当前个人状态只在 [学习进度](../learning/progress.md) 维护；第一课与第二课已完成；第三课「多载荷平衡」讲义与练习已发布，正在学习；其余单元尚未编写。一个条目可按学习反馈拆成多个小课，数学在需要时补齐。

## 前置知识安排

阶段 0 按需插入，第一课已先讲最简单的平面静力例子。向量分解之前补三角函数；速度/加速度之前补导数直觉；运动学之前补矩阵与坐标变换；控制之前补采样、误差与基本微分方程。编程经验用于实现与验证，不要求一开始学习全部高等数学。

## 实践递进

先纸笔图示与 Python → 参数化 CAD → 有适用范围的数值仿真 → 低功率单关节实验 → 多关节集成。实际硬件选型、预算、工具与实验空间在进入对应阶段时确认，不预设用户已有设备。

## Skill 对应关系

- 静力学与材料图示：mechanics-visuals；练习：worked-problem-generator。
- 材料、机械元件：material-selection、machine-element-sizing、tolerance-stackup。
- CAD/图纸：parametric-part-cad、Text-to-CAD cad 与 engineering-drawing；drawing-gdt-review 辅助审查。
- 机构与结构：linkage-synthesis 只用于其支持的平面机构；quick-fea 只在弹性、小变形等模型条件成立时使用。
- 机器人描述：Text-to-CAD robot-simulation。不要把它当完整的 ROS 2 或控制课程。
- 设计交付：engineering-calc-report、dfm-review、design-review-package。

所有真实链接、固定版本和进阶工具分类见 [Skill 来源索引](../resources/skills.md)。机械工具之外的课程，在编写时补充对应官方来源；此处不提前声称完成资料验证。
