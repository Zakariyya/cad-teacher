# 资源目录

- [Skill 来源索引](skills.md)：两个上游、每个 Skill 的直接地址及固定版本。
- [来源登记表](skill-sources.json)：机器可读的仓库提交、路径、Git blob SHA 和快照清单。
- [第三方声明](THIRD_PARTY_NOTICES.md)：复制范围、版权和许可。
- `vendor/baratilab/`：起步课使用的两个 Skill、两个参考文档、一个绘图脚本与 MIT 许可证。是经过固定版本核对的最小快照，不是全部 Skill 安装。

资源存在不代表脚本已运行，也不代表已读完所有进阶 Skill。每课在讲义中另写本次实际读取、运行及验证范围。首次课堂使用本机安装资源；之后为跨设备学习补充本快照，不能把后补快照说成首次课堂运行过的证据。

## 更新方法

先核对上游提交及实际路径，再更新登记表与对应文件。保留许可证；检查 Git blob SHA 和本地版本差异；记录教学影响，重新运行相关算例和学习包检查。不要仅把 main 链接当作可复现版本。
