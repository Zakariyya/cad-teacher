# 在 GPT 网页端继续学习

复制下面内容到已添加项目指令和最新学习包的对话：

```text
请继续 cad-teacher 学习项目。
先读取我提供的 learning/progress.md（或学习包内该章节）、上节作答反馈和项目教学指令。
先用三句话确认：我学到了哪里、还要巩固什么、这节准备学什么。
再列出你实际能使用的资源与执行工具；没有读到的文件、没有运行的程序请直说。
只进行当前进度对应的一个知识单元：先物理意义与机器人例子，再公式与单位。
使用资源目录中对应 Skill 的 references/scripts/examples；无法读取时明确标注。
本课仍出一道基础题和一道工程应用题，等我回答后再判题，不提前透露答案。
结束时整理学习进度更新；如果你不能写回 GitHub，给我可保存的更新文本，不声称已经同步。
```
