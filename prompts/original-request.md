- 约 7 年 Java 后端开发经验，有编程能力。
- 正在从纯软件开发转型至工业机器人开发。
- 已初步学习 GPIO、高低电平、地线、频率、电机驱动器。
- 已安装 Text-to-CAD 和 BaratiLab/mechanical-engineering-skills。

**学习目标：**
未来能够独立进行机器人机械结构设计、CAD 建模、机械臂运动控制、嵌入式开发与 ROS 2 系统集成。

**教学要求：**

1. 首先扫描 mechanical-engineering-skills 的目录及 SKILL.md，识别能够用于机械工程基础教学的 Skill，建立一个循序渐进的学习目录。
2. 每节课优先利用已有 Skill 中的 references、scripts、examples 等内容，而不是只根据模型知识讲解。
3. 对于基础概念，必须先讲物理意义和实际应用，再解释公式及单位，不要直接堆砌数学推导。
4. 每讲解一个概念，尽可能结合真实机器人、机械臂、支架、齿轮、电机、轴承等具体对象。

7. 有条件时利用 CAD、示意图或仿真说明原理，但需要区别几何验证、力学估算、仿真验证和实物验证。

9. 每节课结尾说明学到了什么、它在机器人开发中的作用、下一节需要掌握的前置知识。
10. 不要一次性输出整本教材，每次只进行一个知识单元，并根据我的回答调整难度。
