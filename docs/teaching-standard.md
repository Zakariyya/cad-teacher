# 教材质量与证据标准

## 每课必须具备

学习目标和前置知识；真实机器人对象；物理意义；研究对象与模型；已知和参数来源；假设及其影响；图示；符号、单位、方向；从公式到代入的示例；一道基础题和一道工程题；学生原答与针对性反馈；实际执行证据；本课作用、未解问题和下一步。

来源必须指到具体 Skill 文件/参考文件/脚本及固定版本。脚本内容是可检查的实现，不能因为来自 Skill 就视为正确结论。工程数值应做单位、数量级、极限工况和独立简式检查。

## 分清四类验证

| 类别 | 示例 | 证明范围 |
| --- | --- | --- |
| 几何验证 | 包围盒、孔径、干涉、模型有效性 | 形状与尺寸符合当前几何模型 |
| 力学估算 | 刚体平衡、梁公式、转矩初估 | 指定假设下的载荷或响应估计 |
| 仿真验证 | FEA 网格收敛、动力学求解、控制仿真 | 指定边界、材料、求解器与模型中的数值结果 |
| 实物验证 | 量具、载荷试验、编码器与电流实测 | 特定设备、工况和测量不确定度下的实测表现 |

算术检查是计算内部一致性检查，不自动升级为力学模型、仿真或实物验证。每类分别记录“已执行/未执行/受阻”，不以一个总 PASS 代替证据。

## 能力递进与纠错

第一层：能解释物理意义；第二层：能画图并选择模型；第三层：能列式、计算、检查；第四层：能在条件改变时重新判断；第五层：能用仿真和实测校正模型。课程完成由这些可观察证据决定，不按聊天次数判断。

学生算对但单位或方向错，要分别纠正。记录真实表达，不替学生补写“已经理解”的答案。允许先进入下一课，再用变化题回访弱点。重要公式的纠错应同时更新讲义、答案、脚本和学习包，提交信息说明修正原因。

## 长期内容边界

“从入门到精通”是培养目标，不是质量认证。真实机器人设计还需要制造、电气、控制、调试与现场经验。电路接线、驱动参数和实机试验以具体设备手册为准；教材中的教学近似不直接作为实机验收标准。

Skill 不能覆盖完整的电路、控制理论和 ROS 2 课程。涉及版本行为、产品参数、标准和安全边界时，补查对应官方来源并记录日期，避免从机械工具推导不存在的能力。
